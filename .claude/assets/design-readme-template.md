## File

- **[design-system.md](design-system.md)** — la guida di stile: palette (dark/light se previsto),
  tipografia, spaziature/radius, icone, convenzioni di componente (regole su numeri/mono, controlli
  stilizzati vs nativi...), pattern architetturale per-sezione, harness di anteprima.
- **[decisions.md](decisions.md)** — log delle decisioni di design (scope, cosa si fa ora vs dopo,
  scelte tecniche di implementazione). Formato breve, una voce per decisione.
- **[da-implementare.md](da-implementare.md)** — registro delle funzionalità presenti nel design ma
  assenti nel backend (gap), con priorità e disposizione. **Non implementare senza richiesta
  esplicita del cliente/PM**, anche se sembra una piccola aggiunta — si segna e basta finché non
  arriva conferma.
